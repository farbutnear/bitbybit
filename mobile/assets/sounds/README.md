# Sounds

Everything in this folder ships inside the app.

| File | Plays when |
|---|---|
| `tap.wav` | a button or answer tile is pressed |
| `right.wav` / `wrong.wav` | an answer is checked |
| `done.wav` | a lesson or review session ends |
| `goal.wav` | the session that ends also completed the daily goal |
| `pack.wav` | a card pack is opened (used by packs, coming next) |

These, `memes/womp.wav` and `music/placeholder-loop.wav` are generated by `tools/make_sounds.py`,
so they are original and free to ship. Replace any of them with a file of the same name to change it.

## Adding your own clips: no code needed

- **Meme clips**: put audio files in `memes/`. With meme mode on, a wrong answer plays one at random
  instead of `wrong.wav`. Delete `womp.wav` if you don't want it in the pool.
- **Music**: put audio files in `music/`. As soon as there is a file other than
  `placeholder-loop.wav`, the placeholder stops being used. One track is picked each time the app
  starts and it loops.

Supported: `.mp3`, `.wav`, `.m4a`, `.aac`. Restart `./dev.sh` after adding a file so it is bundled.

Tips:

- Keep meme clips under about 3 seconds; they play on every wrong answer.
- For music, a file made to loop sounds best. `.wav` or `.m4a` loop without a gap; `.mp3` adds a tiny
  silence at the join.
- Only add audio you have the right to use. For a store release that means clips you made, clips in
  the public domain or CC0, or clips whose licence allows redistribution in an app.
